## 🚀 Inicio Rápido

### Requisitos Previos

- Flutter SDK 3.35.0+
- Dart SDK 3.9.0+
- Node.js 18+ (para el servidor API)

### 1. Configurar e Iniciar la API

El proyecto incluye una API REST personalizada en Node.js/Express.

```sh
# Navegar al directorio de la API
cd api

# Instalar dependencias
npm install

# Iniciar el servidor
npm start
```

La API estará disponible en `http://localhost:3000`.

**Endpoints disponibles:**
- `GET /health` - Health check
- `GET /api/v1/cards?page=1&pageSize=20` - Obtener cartas (paginado)
- `GET /api/v1/cards/:id` - Obtener carta por ID
- `GET /api/v1/favorites?userId=user` - Obtener favoritos
- `POST /api/v1/favorites` - Agregar a favoritos
- `DELETE /api/v1/favorites/:cardId` - Eliminar de favoritos

Ver `api/README.md` para documentación completa de la API.

### 2. Ejecutar la App Flutter

En una **nueva terminal**, ejecuta la app Flutter:

```sh
# Instalar dependencias de Flutter
flutter pub get

# Ejecutar en modo desarrollo
flutter run --flavor development --target lib/main_development.dart

# Ejecutar en staging
flutter run --flavor staging --target lib/main_staging.dart

# Ejecutar en producción
flutter run --flavor production --target lib/main_production.dart
```

**Nota:** Asegúrate de que el servidor API esté corriendo en `http://localhost:3000` antes de iniciar la app.

### 3. Configurar URL de la API (Producción)

Para usar una API deployada en producción:

1. Abre `lib/pokemon_cards/data/config/api_config.dart`
2. Cambia `baseUrl` a la URL de tu API en producción:

```dart
static const String baseUrl = 'https://tu-api-deployed.railway.app/api/v1';
```

## 🌐 Traduciones e Internacionalización

Este proyecto usa [flutter_localizations][flutter_localizations_link] y sigue la [guía oficial de internacionalización para Flutter][internationalization_link].

### Agregar Strings

1. Abre el archivo `app_en.arb` en `lib/l10n/arb/app_en.arb`.

```arb
{
    "@@locale": "en",
    "counterAppBarTitle": "Counter",
    "@counterAppBarTitle": {
        "description": "Text shown in the AppBar of the Counter Page"
    }
}
```

2. Agrega una nueva clave/valor y descripción

```arb
{
    "@@locale": "en",
    "counterAppBarTitle": "Counter",
    "@counterAppBarTitle": {
        "description": "Text shown in the AppBar of the Counter Page"
    },
    "helloWorld": "Hello World",
    "@helloWorld": {
        "description": "Hello World Text"
    }
}
```

3. Usa el nuevo string

```dart
import 'package:pokecard_dex/l10n/l10n.dart';

@override
Widget build(BuildContext context) {
  final l10n = context.l10n;
  return Text(l10n.helloWorld);
}
```

### Generar Traducciones

Para usar los últimos cambios de traducciones, necesitas generarlas:

```sh
flutter gen-l10n --arb-dir="lib/l10n/arb"
```

Alternativamente, ejecuta `flutter run` y la generación de código se realizará automáticamente.

## 📝 Notas Técnicas

- **API Local:** La app por defecto consume `http://localhost:3000/api/v1`. Cambia esto en `api_config.dart` para producción.
- **Datos Seed:** La API incluye 21 cartas Pokemon para testing/desarrollo.
- **Caché:** La app usa `dio_cache_interceptor` para cachear responses y mejorar performance.
- **Favoritos:** Los favoritos se almacenan localmente con `shared_preferences` y en memoria en la API (en producción usar base de datos).
- **Flavors:** El proyecto soporta 3 flavors (development, staging, production) para diferentes ambientes.
